# Niger Multi-Cropping

## Description
This provides a detailed overview of the multi-cropping system in Niger, highlighting the specific crops, seasonality, and local agricultural practices. It serves as a guideline for farmers and agricultural enthusiasts.

## Main Entry Point
The main R script for executing the multi-cropping model is located at `Niger_MultiCropping.R`. This script takes into account various environmental and economic factors to provide actionable insights for agricultural management in Niger.

## Contents
- **Niger_MultiCropping.R**: Main script for multi-cropping analysis.
- **Data/**: Directory containing relevant datasets, including climate, soil, and crop data specific to Niger.
- **Figures/**: Contains graphs and figures generated from the analysis.

## Usage
1. Clone the repository:  
   `git clone https://github.com/koendvos/AfricanCropCalendar.git`  
2. Change directory:  
   `cd AfricanCropCalendar`  
3. Run the main script:  
   `Rscript Niger_MultiCropping.R`

## Requirements
- R version 4.0 or higher
- Required R packages:
  - dplyr
  - ggplot2
  - tidyr
